# Protocol

The clu analyst protocol (recall, measurement contract, probe, execute, verify,
report, learn) lives in one place: `skills/clu-core/SKILL.md`. That file is the
source of truth for both direct mode (`claude --agent clu`) and teammate mode
(`/clu` or another agent spawning clu as a subagent).

This file is a pointer, not a copy. Read `skills/clu-core/SKILL.md` for the
actual steps.
