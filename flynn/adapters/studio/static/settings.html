Set up

Run these once in Terminal on this Mac. Studio's chat uses your own Claude sign-in and flynn's agent.
  1. Install the Claude Agent SDKIt also brings the claude command if you don't have it.
    python3 -m pip install --user "claude-agent-sdk>=0.1"
  2. Sign in to ClaudeSkipped automatically when you're already signed in.
    claude auth status || claude auth login
  3. Start StudioOpens http://127.0.0.1:8770. Restart it after updating flynn.
    python3 "$HOME/agent-stack/flynn/adapters/studio/studio.py" serve

How Flynn's AI runs

Claude through the Agent SDK is the default and runs Flynn's full process with its specialists. A model API runs Flynn with another provider's model: it designs and reviews with Studio's design tools, without specialists or a shell.

Connect an AI (MCP)

Let another AI app (Claude Code, Claude Desktop, Cursor, Codex, ChatGPT…) create and change designs in Studio through its MCP server. Each app gets its own token; it works only inside your own runs, and design systems stay read-only.

Effort

Each level sets flynn's model and effort, which models its specialists use, how many review rounds it runs, and a spending cap per message. The chat remembers your choice per conversation; this is the default for new ones. Leave a cap empty for no cap. Changes save as you make them.

Modules

Each new part of Studio arrives behind its own switch, so the way you work today keeps working until you've tried the new one.
